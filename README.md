# aroma-pacifico-roadmap

Backlog of the Aroma Pacífico pilot, the 2026 update of the coffee traceability pilot for Cauca, Huila and Tolima. This repository holds only issues, milestones and labels; work is planned on the [Aroma Pacífico Pilot board](https://github.com/orgs/aroma-pacifico/projects/1). Each issue's "Target repository" field says where its deliverable lives.
